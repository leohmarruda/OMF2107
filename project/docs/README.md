# Mecha Link 2100 documents

Mecha Link 2100 is an independent game inspired by One Must Fall 2097. Older files still use the working names (OMF2107, HAR) until the rename sweep (R22).

- [Development plan](DEVPLAN.md) — the single plan: target, current state, milestones M0 to M7, phases, task register with acceptance checks, rights checkpoint and risks.
- [Game specification](GAME_SPEC.md) — v0.4: the independent game, its modes, rules and acceptance gates.
- [Core loop](CORE_LOOP.md) — one-page session and career loop, with open questions.
- [Feature list](FEATURES.md) — modes, combat, content and platform with milestone and state, plus known doc conflicts.
- [Controls](CONTROLS.md) — default keyboard, gamepad, menu and story-window bindings as found in code.
- [Combat upgrade](COMBAT_UPGRADE.md) — proposal: four attack buttons, S1+C1 grab, components, robot attributes, special traits and subtypes, roster archetypes.
- [Game mechanics](GAME_MECHANICS.md) — v0.8, for the external robot design team: what is fixed, what is open, robot template and archetypes. Supersedes their v0.7 file.
- [Arcade mode](ARCADE_MODE.md) — ladder flow, newscast, hangar, tune-ups, implemented vs missing.
- [Balance and tuning](BALANCE.md) — formulas, difficulty, tune-up values, rules and a tuning log.
- [Original One Must Fall 2097 reference](OMF2097/README.md) — private dev-only comparison material (local, gitignored): never a source of names, art or text for the game.
- [Remastered visual references](Remastered/README.md) — HD move captures for 15 robots, including four new Remastered robots.
- [Imported mesh candidates](mesh/README.md) — inventory and neutral previews of the new FBX exports.
- [Jaguar–Shadow model match review](verification/MODEL_MATCH_REVIEW.md) — accepted
  prototype blockouts, recorded-match comparison, and open animation issues.
- [Stadium and full-match source baseline](verification/STADIUM_BASELINE.md) — measured
  Stadium/Power Plant wall responses and a replayable Jaguar–Shadow result.
- [Ari background prompts](prompts/ARI_BACKGROUND_PROMPTS.md) — Chapter 1 backgrounds (all generated), and [fanservice scene prompts](prompts/ARI_FANSERVICE_IMAGE_PROMPTS.md).
- [Pose authoring](POSE_AUTHORING.md) — mesh landmarks, projection-pose matching and the pose catalog tools.
- [Move catalog](verification/MOVE_CATALOG.md) (generated list), [Shadow baseline](verification/SHADOW_BASELINE.md) and [signature move traces](verification/SIGNATURE_MOVE_TRACE.md).
- [Story treatment](lore/LORE_v2.md) — legacy story in the original game's world; themes only, to be replaced by the new setting (R23). The [lore folder](lore/00_README/README.md) holds the legacy story pack (bibles, outlines, campaigns, registries), kept as source material until each file is rewritten, archived or dropped.
- [Asset ledger](ASSET_LEDGER.md) — origin, use, and distribution status of non-original assets (started with the story portraits).
- [Rights position](RIGHTS.md) — the independent-game decision, release rules, and the research behind it (freeware, Discord, Battlegrounds), asset replacement checklist.
- [Rebrand checklist](REBRAND_CHECKLIST.md) — decisions D1 to D7 and the sweep that removes every original name, design and asset.
- [Engine paths](ENGINE_PATHS.md) — options for a release that needs no original data files, with a recommendation.
- [Mecha pipeline](HAR_PIPELINE.md) (file keeps its old name until R22) — one-source flow for rig, blockout, detailed mesh, poses and collision proxy.
- [Spike A findings](SPIKE_A_FINDINGS.md) — what OpenOMF's rules read, how hits are decided, and the data pack contents.
- [Move measurements](verification/MOVE_MEASUREMENTS.md) — range, timing, damage, and guard for every selectable Jaguar and Shadow attack.
- [Source build baseline](verification/BASELINE.md), [Jaguar combat baseline](verification/JAGUAR_BASELINE.md), and [match contract](verification/MATCH_CONTRACT.md).
- [Image prompts](prompts/) — Ari backgrounds, fanservice scenes and arcade-mode art prompts (listed above).
- [Rights sources](rights_sources/README.md) — saved evidence behind the rights position.
- [Archive](_archive/) — superseded documents kept for history: the Stage 4 plan (scene and flag design; DEVPLAN wins), the first blockout review, the v0.1 game spec (a sequel-style spec) and the design pitch v0.3.

The original OpenOMF documentation remains in the repository's top-level `docs/` folder.
