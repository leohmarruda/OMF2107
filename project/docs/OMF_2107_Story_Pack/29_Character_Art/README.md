# Character artwork production resources

These assets extend Story Pack v2.9 without modifying narrative content.

- `Character_Render_Prompts_v1.0.md`: master style instructions and 23 character prompts (12 playable, 11 supporting).
- `Character_Render_Prompts_v1.0.csv`: structured prompt rows, one per character.
- `Expression_Sprite_Production_List_v1.0.md`: 32 expression types grouped into 8 families.

The style guide in the Markdown prompt catalog should be prepended to each individual character prompt when generating assets from the CSV.
These are render instructions; no image artwork has been generated. Specific appearance proposals remain subject to art-direction approval.
