# NPC-only knockout matchup dossiers — v4.0

**Authority: editorial hypotheses ONLY. None of the 14 proposed winners is approved by this document.**

## Method

- Prioritized the 14 non-established NPC pairings observed in the v3.9 provisional 384-input sample. Counts are samples, **not probabilities**, and do not prove other pairings unreachable.
- Took HAR styles and pilot archetypes from `02_Story_Bibles/Character_Bible_v1.0.md`; any detailed counter is a proposed scene, not an existing feat.
- Every proposal includes opposing counterplay and a required on-screen beat. No opponent-specific performance statistics, distances, damage rules or victory probabilities are invented.
- The seven default exact-pair outcomes remain default-timeline canon and are not reapproved here.

For each pair, reviewer must verify: (1) the exact match is reachable under approved score rules; (2) machine capabilities exist in approved descriptions or receive an explicit new author decision; (3) the draft winner can be defeated by player agency in that pilot’s route; (4) all later scenes use the actual winner and loser; (5) relevant NPC relationship/knowledge state is not overwritten.
