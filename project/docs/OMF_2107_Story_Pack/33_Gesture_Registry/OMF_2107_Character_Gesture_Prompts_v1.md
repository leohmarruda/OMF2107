# OMF 2107 — Character Gesture Sprite Prompts v1.0

**Coverage:** 23 recurring characters, 22 reusable gesture types, 138 character–gesture prompts (six per character).
**Status:** Proposed art-production taxonomy, not yet inserted into screenplay cues. Existing `EXP-*` codes describe facial emotion; `GST-*` describes body gesture. They can be combined independently.

## Rendering contract

Match the approved character master reference exactly: facial features, age, hair, anatomy, silhouette, clothing, accessories and body proportions. Polished semi-realistic illustrated science-fiction fighting-game visual-novel sprite, clean outlines and cinematic cel-shaded rendering. Render one character alone, full-body front three-quarter view, same lens, scale, camera height and illumination as the neutral master. Transparent background, character and hands completely visible, accurate limb anatomy, no scene props except those expressly named, no text, no lettering, no UI, no logos. Do not redesign the costume or change identity. Change body pose and hand placement only; facial expression is a separate EXP layer unless explicitly requested.

Use the approved neutral master illustration as a reference for each render. Do not regenerate a new face for every pose. Produce body-pose layers first; attach expressive face layers separately. Retain consistent visual scale and registered transparent-background crop.

**Accessibility:** Cossette remains seated in her wheelchair; no standing pose variants for her. Kreissack’s movements must respect his life-support structure. **Narrative boundaries:** a flirtatious gesture is not proof of mutual interest, consent, or canon romance.

## Gesture code dictionary

| Code | Type | Visual brief | Category |
|---|---|---|---|
| `GST-REST` | Neutral attentive | Relaxed upright posture, naturally placed hands, clear silhouette | EVERYDAY |
| `GST-OPEN` | Open-handed explanation | One hand extended palm up, other relaxed, conveying explanation or invitation | EVERYDAY |
| `GST-THINK` | Thinking | Fingers lightly at chin or temple, contemplative lean, not obscuring face | EVERYDAY |
| `GST-CROSS` | Guarded arms crossed | Arms crossed at chest, slight weight shift, composed defensive stance | EVERYDAY |
| `GST-POINT` | Assertive point | One hand pointing toward an off-camera subject, assertive but readable | CONFLICT |
| `GST-CHALLENGE` | Competitive challenge | Leaning slightly forward, fist or open hand gesturing a challenge, confident posture | CONFLICT |
| `GST-ANGER` | Contained anger | Tense shoulders, clenched fist near side, restrained body tension; face visible | CONFLICT |
| `GST-DISMISS` | Dismissive wave | Small sideways hand flick, turned shoulder, cool dismissal | CONFLICT |
| `GST-SMIRK` | Playful provocation | One hip cocked, relaxed shoulder, fingers making a tiny teasing invitation | SOCIAL |
| `GST-LAUGH` | Warm laughter | Relaxed shoulders, open hand near chest, natural laugh without hiding face | SOCIAL |
| `GST-FLIRT` | Invitation / flirtation | Subtle forward lean and receptive hand, confident gaze; no unwanted contact | SOCIAL |
| `GST-EMBRACE` | Receptive affection | Open, relaxed arms as if welcoming a consensual hug, no second character | INTIMATE |
| `GST-VULN` | Vulnerability | Hands lightly clasped or one palm against chest, shoulders lowered, unguarded stance | INTIMATE |
| `GST-WITHDRAW` | Boundary / withdrawal | One open palm raised in a clear stop gesture, balanced firm stance | INTIMATE |
| `GST-TRIUMPH` | Victory celebration | One arm raised, energetic athletic posture, visible face | ACTION |
| `GST-READY` | Pre-fight readiness | Athletic preparatory stance with balanced feet and hands in readable silhouette | ACTION |
| `GST-OBSERVE` | Watchful suspicion | Weight back, head turned slightly, one hand near body, alert quiet attention | INVESTIGATION |
| `GST-DEVICE` | Portable data inspection | Holding a small blank holographic tablet or wrist device angled away from face | INVESTIGATION |
| `GST-REVEAL` | Evidence presentation | Holding a generic unmarked data chip or folder toward off-camera audience | INVESTIGATION |
| `GST-COMMAND` | Controlled authority | Straight-backed, one hand issuing a concise instruction, composed posture | AUTHORITY |
| `GST-HESITATE` | Conflicted hesitation | Half-extended hand stopped mid-motion, uncertain weight shift | INNER |
| `GST-EXHAUST` | Tired recovery | Slightly slumped posture, hand resting on knee or railing implied off-screen; no injury | INNER |
