# Ari campaign repair (v1.2)

**Read first:** `Ari_Route_Spec_v0.1.md`, then `Ari_Alternate_Scenes_v0.1.md`. The active Ari screenplay is `../04_Screenplay_Reconstructions/Chapter_01…06_*_v0.3.md`; v0.2 chapters remain intact as the v1.1 baseline and historical source. They are **not** alternate current routes.

`ari_route_validator.py` transforms on-screen Selene/Crystal match results into the engine's order, then returns the authoritative branch scene keys, winner, finalist list, legal fight access, a dated event stream, evidence choice, romance/medical flags, and any unresolved NPC results. The tests do not evaluate prose aesthetics or interpersonal plausibility.

Ari now has scripted loss and early-elimination continuations and no longer automatically receives a championship after losing. The original default (beat Selene; lose Crystal; beat Mara, Crystal and Lyra) is preserved.

All proposed new romance details and the provisional public three-way seeding remain awaiting approval.
