# Fanservice review registry — v2.9

- **Active tags:** 65 scenes across the twelve pilot scripts and Christian's supporting subplot.
- **Proposal-only cards:** 12 from the older standalone scene bank.
- **Script tag syntax:** `**[FANSERVICE: FS-CODE | type=... | scope=... | status=REVIEW | note=...]**`.
- `FULL_SCENE` = scene primarily contains optional visual appeal, flirtation or spectacle; `OPTIONAL_BEAT` = only an independently gated branch or portion.
- The review anthology contains the entire original scene text and all dialogue/choices; it is not a selected quotation collection.
- The CSV/JSON index provides stable identifiers and the new active-script source paths.
- Underlying chronology, BG/MUSIC/PERF cues, matches, dialogue and story flags have not been edited.
- Tags for manipulation and domination are for **narrative review**, not an indication that exploitation should be sexualized, rewarded or allowed to bypass affirmative consent.
- Historical scene cards are **proposals** and may duplicate or conflict with active scenes. They are not inserted in active routes by this release.
