# Ren campaign v0.1

Six screenplay chapters, branching specification and prototype validator for playable Ren Akiyama. **Draft, not approved final canon.** The new civilian character Tessa and optional romance routes are proposals. No official fight ends in a draw; the Nova boss fight is outside the official bracket. Group cinematic order (Raven then Mara) is deliberately different from tournament model input order (Mara then Raven): the adapter maps by opponent. Tests validate route consistency, not cinematic quality or implementation feasibility.

Run: `python3 -m unittest discover -s 11_Ren_Campaign -p 'test_*.py' -v` from the package root.
